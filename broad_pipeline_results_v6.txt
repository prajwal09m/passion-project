============================================================
INTERPRETATION
============================================================

The v6 results with professional trader-inspired features show significantly worse performance compared to v5:

- Test set AUC dropped from 0.4960 (v5) to 0.4421 (v6)
- Backtest return dropped from +30.17% (v5) to -4.77% (v6)
- Sharpe ratio dropped from 1.93 (v5) to -5.58 (v6)
- Win rate dropped from 36.87% (v5) to 12.50% (v6)

Possible reasons for degradation:
1. **Overfitting**: 86 features may be too many for 365 signals (4:1 feature-to-sample ratio)
2. **Feature noise**: Many new features may not be predictive for this specific pattern
3. **Dataset size**: Fewer signals (365 vs previous) reduces statistical power
4. **Feature redundancy**: Some engineered scores may duplicate existing information

Key observations:
- Top features are still zone quality metrics (base_range_pct, zone_width_pct)
- Market context features (spy_return_50d, iwm_return_20d) show importance
- Many new professional trader features did not make top 10

RECOMMENDATION:
- Reduce feature set to most predictive features only
- Increase dataset size or reduce feature complexity
- Focus on zone quality and market context features that showed importance
- Consider feature selection to remove noise features
