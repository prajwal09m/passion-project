# Milestone 11 Collaboration

Ordering: assignments → briefs → one ledger-funded extra
experiment → challenges → resolve-or-preserve → independent
verdicts. Dependencies tracked in the team report
(`extra_experiment` cites the designer's spec id; disagreements
cite challenge + resolution; judge cites moving-ref counts).

Resolution rule: a discriminating measurement decides; three
agents agreeing without one do not. Unresolved disagreements are
first-class outputs carried into M12 follow-up proposals, never
silently dropped or majority-voted.
