# Milestone 11 Evaluation

Per-agent: role contracts (7 tests) — adherence by construction
(each role's output schema asserted). Discovery contribution: the
designer's extra spec is logged separately from the baseline spec
list, so its marginal value is auditable. Useful disagreement:
skeptic challenges counted by type; blocking challenges require
resolution text. Error detection: planted unsupported-support
caught; evidence-free support downgraded by judge. Redundancy:
designer reports alternative count; same-tool reruns refused by
the inventor. Cost: every reservation logged with agent + tool;
team cost = baseline + ≤1 extra experiment.
