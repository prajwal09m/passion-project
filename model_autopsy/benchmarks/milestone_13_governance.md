# M13 Governance

OFFLINE and PROPOSAL always allowed; PROTECTED (paid, destructive) requires a human-issued single-use token (m12/authorization issue, require, consume). Scheduler defers paid work to awaiting-approval; UI never mints tokens. Live governor caps rounds 3, experiments 6, attempts 12, tokens 50k, spend 0.40 USD, enforced pre-request with atomic reserve and settle. Tests cover paid refusal, budgets, and idempotency.
