# Evolution History: Demand Zone AI

**Evidence basis:** curated public release, local repository files available to the supervisor, and the archive-only v1.0.1 audit. This is a traceable synthesis, not a reconstruction of missing training runs. The historical versions do **not** form a validated linear performance ladder.

## Current evidence boundary

- The frozen `DZAI-MARKET-STRUCTURE-ABLATION-V1` protocol is labeled v1.0.2, but it is unexecuted. It is not the current champion.
- `outputs/study_v1/` preserves a historical v1.0.1 archive, including event/OOF tables and eight fitted estimators. Saved rows and point metrics passed archive-level consistency checks, but exact original source was not recovered. The reconstruction differs on `rsi14`, `atr_pct`, and `zone_width_pct` for all 480 scoped AAL rows; archived confidence intervals were not reproduced.
- Raw OHLCV, the V2 roster-level dataset, and point-in-time universe data are absent from this public checkout. No prospective predictions/outcomes exist. No historical version currently satisfies the requirements for an independently reproduced CHAMPION.
- V2–V10 change labels, datasets, features, or evaluation. Cross-version AUC comparisons are therefore not evidence that later versions improved the same task.

## Durable conclusions for future work

1. **Do not compare reported AUC across V2–V10 as a version delta.** Targets, rows, features, splits, and evaluation changed.
2. **V1.0.1 is an archive, not a validated champion.** Saved score consistency does not repair missing original source or feature mismatch.
3. **V1.0.2 is a frozen protocol, not an executed model version.** No new version should be numbered until the evidence package is reproducible and accepted.
4. **AUC is not profitability.** The V2 simulation summary and broad V6 pipeline show why backtest evidence needs separate, realistic analysis.
5. **Leakage controls must be fold-local.** Full-data imputation, outcome-derived encodings, forward-return fields, overlapping labels, timestamp alignment, and survivorship selection are explicit audit targets.
6. **Research memory must preserve failed/blocked experiments**, but distinguish them from scientific discoveries and paper claims.
