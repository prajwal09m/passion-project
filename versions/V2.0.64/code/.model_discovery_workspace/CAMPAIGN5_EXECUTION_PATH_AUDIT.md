## Preflight enforcement details

`autonomous_agent/campaign5_authorization.py` checks exact schema keys and version, C5 identity and run scope, exact campaign protocol pin, scope equality/digest, authorized dataset operations and deny paths, approved predeclaration hash/protocol/scope link, owner and independent-reviewer decisions, reviewer independence/qualifications/conflicts, expiration, distinct configured trust identities and signatures, plus exact hashes of the predeclaration and boundary artifacts. Missing/unavailable identity keys, records, pins, files, malformed data, or audit-write failure fail closed. An append-only machine-readable decision record is written to the C5 state audit log. It does not create approvals.

Signatures are HMAC-SHA256 using separate externally provisioned owner/reviewer keys and trust actor IDs in environment (`C5_OWNER_HMAC_KEY`, `C5_REVIEWER_HMAC_KEY`, `C5_OWNER_ACTOR_ID`, `C5_REVIEWER_ACTOR_ID`). These are not configured in this checkout; no authoritative C5 authorization exists. The synthetic test positive control is explicitly non-authoritative and cannot pass the runtime preflight.

## Coverage and limitation

Execution inside the existing autonomous supervisor/continuous-loop and adapter boundary is mechanically guarded, and targeted adversarial tests verify no work starts when C5 authorization is absent. **Repository-wide protection is not established:** the legacy research scripts can be directly invoked outside this machinery. No known approved C5 record is present, so it would be unsafe to invent a C5-specific signed record or to retrofit a global lock that would change unrelated historical workflows. Human owner must define whether legacy scripts are in scope and authorize a bounded safe remediation. The C5 adapter, supervisor custom-runner, continuous-loop driver/cycle/direct execution, reproduction CLI, and baseline-establishment API are guarded before experiment work; no signed allowed C5 path was tested because no authentic authorization exists. Resume recovery only adjudicates existing durable results and does not rerun experiments. Until the owner scopes legacy entrypoints, coverage is incomplete and not repository-wide.
